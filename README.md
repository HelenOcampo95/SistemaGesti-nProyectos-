Breve descripción del proyecto.

## Tecnologías utilizadas

- Laravel
- Vue.js
- MySQL
- Bootstrap / Metronic

## Requisitos

- PHP >= 8.2
- Composer
- MySQL

## Instalación

### 1. Clonar repositorio

```bash
git clone https://github.com/HelenOcampo95/SistemaGesti-nProyectos-.git
```

---

## 2. Ingresar a la carpeta del proyecto

```bash
cd SGP
```

---

## 3. Instalar dependencias de Laravel

```bash
composer install
```

---

## 4. Instalar dependencias de Node.js

```bash
npm install
```
# Ejecutar el Proyecto

## Iniciar servidor Laravel

```bash
php artisan serve
```

---

## Ejecutar Vite

```bash
npm run dev
```

---

## Ejecutar WebSockets

```bash
php artisan websockets:serve
```
